advance_beamlab.abmc_stability_curve#

advance_beamlab.abmc_stability_curve(info, forward, data, template, *, cov=None, noise_cov=None, P_range=(0.0001, 10000.0), n_coarse=17, n_refine=9, reg=0.0, f=1.0, max_lag=None, return_optimal=False, verbose=None)#

Explore the template-constraint trade-off \(P\), then refine it.

Shirani et al. (2024) [1] state that \(P\) “is empirically adjusted” and report no value for it, because the useful setting depends on the recording: the paper’s own data is 20-32 subdural contacts, which is a different regime from a whole-head MEG array. This function does that adjustment on your data, in two stages.

Coarse exploration. \(P\) is swept logarithmically across P_range. Each value is scored on three things that together say whether the method is operating at all: the coupling \(P\,g^\mathsf{T}c / g^\mathsf{T}g\), which must not have underflowed to nothing or the template constraint is inert and ABMC degenerates to a plain LCMV; the fraction of grid weights that have blown up, which marks the paper’s non-convergence regime at large \(P\); and the location of the localiser peak.

Refinement. The widest run of consecutive viable values over which the peak does not move is the plateau. Its edges are then re-sampled more finely and the geometric centre of the refined plateau is returned.

What the lower end of the sweep is, and is not. The coupling test is a numerical one: it rejects a \(P\) at which the constraint has vanished into round-off, at the same threshold as the “numerically inert” warning of make_abmc(). It is not a test that the constraint is doing anything, and on the default P_range it never fires at all – at \(P=10^{-4}\) the coupling is already of order \(10^{-4}\), some ninety times the threshold. That matters because the \(P\to 0\) limit is exactly an LCMV beamformer, so wherever LCMV already peaks where ABMC does, the peak is stable from the bottom of the sweep upwards and the plateau is anchored there. The returned \(P\) is then set as much by P_range[0] as by the data: on the eight-source spherical-EEG fixture of examples/plot_abmc_localization.py the selection had a median of 0.0075 on the default range, 0.0013 with the range extended down to \(10^{-6}\), and 0.081 with it started at \(10^{-2}\), on identical data. At the default-range selection the constraint moved the weights by only 0.4 to 1.1 per cent away from the \(P\to 0\) limit.

That is a limitation rather than a failure: the localisation was the same to the grid resolution at every one of those settings (mean peak error 0.85 cm throughout), which is what a plateau is supposed to mean, and it is why the threshold is left where it is. But read the returned \(P\) as the lowest setting at which the answer is already stable, not as the setting at which the template constraint earns its keep. If you want the latter, start the sweep at the bottom of the range make_abmc() recommends, i.e. P_range=(0.01, 1e4); on the same fixture that selects 0.037 to 0.096, where the weights differ from LCMV’s by 4 to 11 per cent, with no loss of accuracy.

The upper edge is not arbitrary. Eliminating \(\beta_1\) from Eq. 17 using Eq. 19 leaves an affine recursion whose linear part is \(\Pi(I - \mu R)\), with \(\Pi = I - d g^\mathsf{T}/(g^\mathsf{T}d)\) an oblique projector and \(d = g + Pc\). The obliquity, and hence the norm of \(\Pi\), grows as \(g^\mathsf{T}d = g^\mathsf{T}g + P\,g^\mathsf{T}c\) shrinks. Consequently, wherever \(g^\mathsf{T}c < 0\) there is a \(P\) at which \(g^\mathsf{T}d\) vanishes and the oblique projector is undefined; the smallest such \(P\) over the grid is reported as ABMCResult.critical_p. It is the pole of the constraint’s denominator, which is an upper bound on the “threshold for each segment” the paper reports without deriving, not that threshold itself: the descent’s spectral radius \(\rho(\Pi(I - \mu R))\) can reach one before the denominator reaches zero, so the iteration may already diverge below critical_p. Note also that critical_p is the pole of the iterative descent’s denominator; the default method='closed-form' solver has its own pole, at the smallest \(P\) with \(g^\mathsf{T}R^{-1}g + P\,g^\mathsf{T} R^{-1}c = 0\), which the two solvers do not share. The threshold is what bounds the sweep from above, but not where the answer stops being trustworthy: the peak can move well below it, which is why the viable range has to be found per dataset rather than assumed.

Selection is by stability rather than by score, deliberately. The template match tends to increase with \(P\), a stronger constraint pulling the output towards the template whether or not the location is right (it is not monotone in general, but it rises over the working range). Choosing the \(P\) that maximises it would therefore be circular. A plateau over which the answer is unchanged is evidence about the data; a maximum of a self-referential score is not.

Parameters:
infoinstance of mne.Info

Measurement info (channel set only).

forwardinstance of mne.Forward

Forward solution, as for make_abmc().

datainstance of mne.Evoked | instance of mne.io.Raw | ndarray

The sensor data segment, as for make_abmc().

templatendarray, shape (n_times,)

The desired-source waveform, as for make_abmc().

covinstance of mne.Covariance | None

Covariance for the beamformer. None estimates it once with sbl_covariance() and reuses it for every \(P\).

noise_covinstance of mne.Covariance | None

Noise covariance, as for make_abmc().

P_rangetuple of float

Inclusive (low, high) bounds of the logarithmic sweep. low is not a formality: when the peak is stable all the way down to it, the plateau begins there and the selected \(P\) moves with it. See the note above on the lower end of the sweep.

n_coarseint

Number of points in the coarse sweep.

n_refineint

Number of points in the refinement sweep. Set to 0 to skip refinement and return the coarse plateau centre.

regfloat

Diagonal loading, as for make_abmc().

ffloat

Distortionless gain, as for make_abmc().

max_lagint | None

Template-lag search window, as for make_abmc().

return_optimalbool

If True, also return the selected \(P\).

verbosebool | str | int | None

Control verbosity of the logging output. If None, use the default verbosity level. See the logging documentation and mne.verbose() for details. Should only be passed as a keyword argument.

Returns:
p_valuesndarray, shape (n_points,)

The values of \(P\) evaluated, ascending (coarse and refinement points merged).

peakndarray of int, shape (n_points,)

Index of the localiser peak at each \(P\).

template_matchndarray, shape (n_points,)

Peak template-match value at each \(P\). Reported for inspection; it is deliberately not the selection criterion.

blowupndarray, shape (n_points,)

Fraction of grid weights that blew up at each \(P\).

couplingndarray, shape (n_points,)

The realised constraint coupling at each \(P\).

p_optfloat

The selected \(P\); returned only if return_optimal is True.

See also

make_abmc

Pass P='auto' to use this selection directly.
